**Date:** 2026-01-06 (EAT)

## Done

- Standardized admin success payloads end-to-end (backend + UI + tests) while preserving the existing error shape:
  - Success now includes `status`, `ok`, and `message` (and keeps any existing fields for compatibility).
- Updated UI behavior:
  - Save now treats success as `(status === "ok" || ok === true)` and prefers `data.message` for toast/status.

- Fixed Psalm gate failure caused by redundant string casts on timestamp headers:
  - Removed `(string)$timestamp` for `X-NC-TIMESTAMP` and `X-Timestamp`.
