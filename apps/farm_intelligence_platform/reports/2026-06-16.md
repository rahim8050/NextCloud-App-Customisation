# 2026-06-16 — Schema-based endpoint conversion (all controllers)

## Summary

Converted all remaining hardcoded Django backend endpoint paths to schema-based lookups via `DrfSchemaService`. Every proxy route in the app now reads its HTTP method, path, query params, and body fields from the DRF OpenAPI schema instead of hardcoded strings.

## Changes

### New generic `getOperation()` method (`lib/Service/DrfSchemaService.php`)
- `getOperation(string $operationId, string $correlationId): array` — loads the schema, normalizes it, and extracts a single operation by DRF operationId without needing a domain-specific map.
- Added 8 missing operation IDs to `FARM_OPERATION_IDS`: `weather_current`, `weather_hourly`, `weather_daily`, `ndvi_job_status`, `ndvi_ingest`, `ndvi_circuit_breaker_reset`, `ndvi_upstream_health`.
- Removed `final` from class declaration so PHPUnit can mock it.

### Controllers converted (6 controllers, ~40 methods)
Each received `DrfSchemaService` DI, an `OPERATION_IDS` constant with guessed DRF operationIds, and all proxy methods rewritten to use `getOperation()`/`getFarmOperation()`:

| Controller | Files | Methods |
|---|---|---|
| `AdminFarmsController` | existing | 8 weather/NDVI/farm-state methods |
| `AdminAlertsController` | **new** | `broadcast` |
| `AdminApiKeysController` | **new** | `listKeys`, `createKey`, `revokeKey`, `rotateKey` |
| `AdminRadioController` | existing | 14 methods (full controller) |
| `RadioUserController` | existing | 7 methods |
| `PodcastsController` | **new** | 5 methods |
| `UserAlertsController` | **new** | 7 methods |

### Response standardization
All converted controllers now use `buildSuccessResponse()` wrapping (`{ status, data }`). Secret-bearing responses (key create/rotate) include `Cache-Control: no-store`.

### DI registration fixed (`lib/AppInfo/Application.php`)
Added `DrfSchemaService` container argument to 5 controller registrations that were missing it.

### Test fixes
- Fixed NDWI test assertions (`mean_ndwi` nesting; `requireAll=true` for raster).
- Added `DrfSchemaService` mocks to all affected controller tests.
- Fixed schema mocks with proper `bodyFields` and `queryParams` so `filterBodyParams` accepts valid params.
- Added `getParams()` stubs where controllers derive query params from the request object.

### Gate result
`composer run gate` — **OK** (lint + cs:check + psalm + 202 tests / 1122 assertions).
