# 2026-06-19 — NDWI admin UI wiring + card label fix

## Summary

Wired NDWI endpoints into the Nextcloud admin settings UI (buttons, data attributes, JS event handlers). The NDWI buttons were already added to the template and JS constants but the form's data attributes were missing, so requests never reached Django. Also fixed card labels showing "NDVI" instead of "NDWI".

## Changes

### NDWI data attributes (`templates/settings/admin.php`)
- Added missing `data-farm-ndwi-*` attributes to the form tag (latest, timeseries, raster, queue, refresh, farm-state)
- These were generated by `AdminSettings.php` but never output in the template
- NDWI requests now reach Django (confirmed 200 responses for farms 17 and 21)

### NDWI card labels (`js/ndvi-latest.js`, `js/admin-settings.js`)
- `ndvi-latest.js` exports `buildLatestCardModel` / `buildTimeseriesCardModel` via `window.FarmIntelligencePlatformNdviUi`, which `admin-settings.js` uses preferentially
- Added `label` parameter to both functions in `ndvi-latest.js` (the override) and `admin-settings.js` (the fallback)
- NDWI callers pass `'Latest NDWI'` / `'NDWI timeseries'`; NDVI callers continue passing `'Latest NDVI'` / `'NDVI timeseries'`
- All summary strings in the card model (loading, error, no_data, empty) use the label instead of hardcoded "NDVI"

### Nextcloud config permissions (system fix)
- `config.php` was owned by `root:www-data` — Nextcloud couldn't write to it
- Changed ownership to `www-data:www-data`
- Removed ACL from `config/` directory (mask was restricting write access)

### NDWI JS wiring (`js/admin-settings.js`) — pre-existing
- 6 NDWI URL constants, 6 DOM element refs, 2 NDWI state variables
- NDWI enable/disable in `setFarmsActionsEnabled` / `updateNdviActionState` / `resetNdviState`
- 6 NDWI event handlers (latest, timeseries, raster PNG, queue, refresh, farm state)
- NDWI sharing NDVI's date inputs, calendar, table, raster preview, and farm-state output panel

### NDWI PHP backend (`lib/Settings/AdminSettings.php`) — pre-existing
- 6 NDWI URL generation entries (`farmNdwiLatestUrl`, `farmNdwiTimeseriesUrl`, etc.)
- Also added missing radio emergency/TTS URLs

### Other pre-existing
- `resources/openapi.yml`: 716 lines of NDWI operationId additions
- `tests/unit/Settings/AdminSettingsTest.php`: test updates for new URL vars
- `appinfo/info.xml`: version 0.0.3 → 0.0.5 (2 bumps for cache invalidation)

## Notes

- No NDWI observation data exists in the database (486 NDVI records, 0 NDWI). Endpoints return empty/null gracefully.
- Django 403 on farm 29 is a configuration issue (farm lacks `FarmIntegrationAccess` for the Nextcloud integration client), not a code bug.
- Version 0.0.5 deployed via `occ app:disable && occ app:enable`.
