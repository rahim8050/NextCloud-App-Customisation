# Daily Report — 2026-05-15

## Summary
Wired farm-scoped activity endpoints and radio endpoints into the Nextcloud admin UI, resolved response parsing issues with Django/Nextcloud envelope formats, and fixed activity creation for integration token users.

## Changes

### Django Backend (`farm-intelligence-platform`)
- **HMAC signature fix**: Switched from hex to base64 encoding to match Nextcloud's `WeatherApiClient.php` output, and added support for both hex and base64 in verification.
- **Activity creation fix**: Resolved owner resolution for `IntegrationTokenUser` so activities can be created without a real Django user.
- **Farm-scoped activity views**: Created `farms/activity_views.py` with CRUD operations mirroring `farms/observation_views.py`, wired into `farms/urls.py`.
- **Tests**: Added comprehensive tests for farm activity views; fixed mypy union-attr error.

### Nextcloud App (`farm_intelligence_platform`)
- **Farm-scoped activities**: Added proxy methods in `AdminFarmsController.php`, routes in `appinfo/routes.php`, and wired into admin UI with schema-driven form fields matching `ActivityCreateSerializer`.
- **Radio section**: Created `AdminRadioController.php` with proxy endpoints for providers, stations, and stream URLs. Added UI with stations/providers tabs, filters, and audio player modal.
- **Response parsing fixes**:
  - Django returns `status: 0` (integer) for success, not `status: "ok"` (string) — updated JS success checks.
  - Nextcloud OCS API wraps responses in `{ ocs: { meta, data } }` envelope — added `unwrapOcsEnvelope` and `isOcsSuccess` helpers.
- **CSS fixes**: Fixed radio modal z-index, backdrop click to close, and `[hidden]` attribute override with `!important`.
- **Version**: Reverted `info.xml` to `0.0.3` to avoid triggering Nextcloud maintenance mode.
