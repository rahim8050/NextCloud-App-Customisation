# Daily Report — 2026-05-18

## Summary
Replaced audio `timeupdate`-based progress tracking with an elapsed-seconds timer for live radio streams, since live streams have `Infinity` duration and don't fire meaningful `timeupdate` events.

## Changes

### Nextcloud App (`weather_apis`)
- **Elapsed timer**: Replaced `radioAudio.addEventListener('timeupdate', updateProgress)` with a `setInterval`-based elapsed timer (`radioElapsedSeconds`) that ticks every second.
- **Progress bar locked**: Removed the click-to-seek and rewind/forward handlers since seek is not useful on live streams (no seekable range).
- **Cleanup**: Added `stopElapsedTimer()` call on player close; timer starts on `play` and stops on `pause`.
- **Format fix**: Loosened `formatTime` validity check (removed `!isFinite(seconds)` guard since elapsed seconds are always finite).
