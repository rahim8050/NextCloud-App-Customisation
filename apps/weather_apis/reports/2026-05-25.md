# Daily Report — 2026-05-25

## Summary
Reintroduced live-seeking progress bars for radio streams using the `seekable` time range, added live/elapsed badges, and replaced the simple elapsed timer with an `rAF`-driven progress animation for smooth rendering across both the bar and modal player.

## Changes

### Nextcloud App (`weather_apis`)
- **Live seekable-aware progress**: `updateProgressBars()` now reads `radioAudio.seekable` to determine a live window. When no `seekable` range exists (or `duration` is `Infinity`), falls into "live mode" — progress is calculated relative to the seekable window and renders an animated sweeping fill.
- **Live badge**: Added `LIVE` pill indicators (orange badge with pulsing dot) to both the collapsible bar (`#weather-apis-radio-bar-live`) and the modal player (`#weather-apis-radio-player-live`), shown/hidden based on `isLive` detection.
- **Click-to-seek on live streams**: `seekRadioToPercent()` maps a click ratio into the seekable window range and sets `radioAudio.currentTime` accordingly.
- **rAF-driven animation**: Replaced `setInterval` with `requestAnimationFrame` for smooth 60fps progress bar updates. `cancelAnimationFrame` on cleanup.
- **CSS animations**: Added `weather-apis-live-sweep` (pulsing fill) and `weather-apis-live-glint` (shimmer across track) keyframes for live mode.
- **Template updates**: Added `LIVE` badge elements to both bar and modal player.
